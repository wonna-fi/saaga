## Documentation Templates

Every document follows the template for its type. Match the structure so
verification can compare against it: a section marked optional is omitted outright
when it does not apply — never kept as an empty heading or an "N/A" stub — and
where a template offers a choice of heading, pick one. Adapt code examples, file
references, and terminology to the application's language and framework
conventions — the plan's **Template Adaptations** section records any deltas that
apply to this repository.
